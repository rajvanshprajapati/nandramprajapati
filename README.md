# Davisson-Germer Experiment - Simulation and Notes

This repository contains explanation and simulation of the Davisson-Germer experiment which proves the wave nature of electrons.

## What is this experiment?
In 1927, Davisson and Germer proved de Broglie's hypothesis (λ = h/p) by showing electron diffraction from a Nickel crystal.

## Key Concepts Covered
- Wave-Particle Duality
- Wave Velocity: v = f * λ
- Alternating Current (AC): i = Im sin(wt)
- Frequency and Time Period: f = 1/T
